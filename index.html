02 / Projects / 2025

CIS Hardening Toolkit

2025 · bash · Ubuntu 22.04 · docs

Modular Bash that hardens Ubuntu 22.04 across authentication, SSH, kernel sysctls, logging, firewall, AppArmor and sudo. The firewall module adds SSH brute-force rate limiting, anti-spoofing, scan protection and a strict outbound allowlist. The validator runs 73 CIS L1 controls and emits a PASS/FAIL/WARN dashboard.
